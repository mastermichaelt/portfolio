Codenames AI

An AI-assisted board game where the system gives clues and the player guesses — designed so first-time solo players can start confidently in under 30 seconds.

Product AIAgentsEval loopsProgressive disclosure

Problem Role System overview Key decisions Outcomes Evidence Related

Problem

Classic Codenames has a steep first-round learning curve. Solo players bouncing between AI Spymaster and guessing need role clarity before they care about strategy depth.

Role

Product engineer / interaction designer for the onboarding and help surfaces; owner of the AI role framing, turn-outcome education, and progressive disclosure model.

System overview

Players open a native dialog that explains the loop: AI gives the clue, you guess, closing starts the game. Collapsed reference sections put AI roles before Guess outcomes. Outcome rows use semantic status treatment without turning help into a manual.

System overview · Codenames AI

Key engineering decisions

Decision 01
Loop first

Lead with the play loop instead of rule encyclopedias — confidence beats completeness on first visit.

Decision 02
Role order

Show AI Spymaster / AI Operative before Guess outcomes so players know who acts when.

Decision 03
Native dialog

Keep the production dialog posture (top-anchored on mobile, centered on desktop) so the prototype stays implementation-faithful.

Decision 04
Evidence in UI

Guess outcomes use semantic icons and scoped status color only in that section — clarity without palette sprawl.

Outcomes

  • First-visit path reduces to one modal: understand loop → optional deepen → Got it starts play.
  • Help content is progressive: roles and outcomes are available without blocking the CTA.
  • Design decisions documented as a Design-mode artifact ready for engineering handoff.

No invented KPIs — outcomes are qualitative until you supply measured results.
