# Prototypes

Standalone HTML/CSS/JS design prototypes. They are **temporary** review artifacts for IA, visual direction, and interaction — not production sources and not a long-lived second design system.

Do not import files from this folder into the Next.js build. Production truth stays in `app/`, `components/`, and app styles.

After a prototype’s look/IA has been ported into production routes, delete the package (see the active portfolio MVP plan’s `prototype-cleanup` slice). Prefer git history over keeping stale HTML around.
